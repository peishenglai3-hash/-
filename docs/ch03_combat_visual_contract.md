# 第三章战斗持械表现契约

当前工程是 Phaser 3 的 2D 像素运行时，因此持械“建模”采用可替换分层资产：角色底图、武器层、枪口火光、弹道和命中反馈分别由运行时控制。角色素材不重新烘焙武器，避免陈继南、董云庭和团丁在不同朝向之间出现比例漂移。

本轮已经接入：

- 陈继南：短枪/长枪独立图层，随鼠标方向旋转；
- 团丁：短枪独立图层，随敌人瞄准方向旋转，失去抵抗后隐藏；
- 董云庭：长枪独立图层，进入战斗后自动瞄准活动团丁并提供协战火力；
- 统一原点、显示尺寸和锚点记录在 `public/assets/ch03/combat/armed-actor-profile.json`；
- 火光、弹道和命中反馈保留为运行时特效，不写入角色 PNG。

如果后续明确授权外部 2D→3D 服务，可将同一角色/武器接口替换为渲染帧；在此之前不上传本地美术素材，也不把无法由 Phaser 直接消费的模型作为运行时依赖。
