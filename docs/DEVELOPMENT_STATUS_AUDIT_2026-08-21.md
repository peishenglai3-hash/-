# 《红色源代码：洪湖篇》开发状态与全流程核查

核查日期：2026-08-21
核查范围：序章、第一章、第二章、第三章、第四章当前代码与已纳入仓库的运行时资源。
运行时：Phaser 3.90 + Vite 5 + Vue 3 + Pinia；本仓库不是 Godot 工程，Godot 相关技能用于场景、输入、物理、动画和导出原则核对，实际实现仍以 Phaser 为准。

## 一、当前开发流程

1. 剧情锁定：将剧本拆成场景、叙事段、交互任务、正式选择、固定历史节点和汇合点。
2. 资产化：地图使用分层地图 JSON/图层资源，人物、头像、道具、视频和 BGM 按章节目录纳入 `public/assets`。
3. 场景实现：Phaser 场景负责地图、碰撞、人物位置、粒子和场景状态；Vue HUD 负责任务、对话、选择、结果、转场和终局画像。
4. 系统结算：正式选择通过统一的行动/画像接口写入后端状态；前端只展示选项和剧情反馈，不展示风险、画像数值或增量。
5. 保存与回放：场景切换自动存档、固定检查点、手动槽位和章节入口快照均经过校验和迁移；标题界面可读档并重玩已记录章节。
6. 发布门禁：内容契约、系统契约、章节契约、TypeScript、生产构建和 Playwright E2E 通过后，再检查 Git 工作树、提交 SHA、远端分支和可达性。

## 三、五个核查维度与已处理事项

### 1. 内容完整性

- 序章至第四章的正式入口、章节收束和固定历史节点均由内容锁与章节契约检查。
- 第三章七个正式选择均为 A/B/C/D，且节点级画像、风险和标签与当前剧本逐项对应。
- 第四章场景一至六、涂济洲、彭定邦、杜家团防和王爷庙地点文本均有契约锁；彭国材仅保留在旧素材文件名的来源边界。
- 第二章地图预览模式不再弹出“剧情尚未接入/接入点”类开发文案，避免玩家把编辑器对象误认为正式任务。

### 2. 画面、章节衔接和音频

- BGM 统一经过受控音轨：场景 BGM 使用 Phaser 管理并读取设置音量；战斗/环境音效仍走独立 Web Audio，避免同一音效被全局 Phaser 总线重复放大。
- 视频显示统一使用 `contain` 和黑底，保留完整画面比例；章节切换使用 1 秒黑幕，场景淡入淡出时间与转场逻辑一致。
- 已对第三、第四章开场、章末、固定历史节点和场景五视频做浏览器加载/显示尺寸回归。当前环境没有 `ffprobe`/`mediainfo`，因此未把浏览器解码尺寸冒充源文件原始编码尺寸，也未宣称已完成 LUFS 级响度测量。

### 3. 任务设置与玩家引导

- 选择面板支持键盘 A-D、方向键、Enter/Space，并在打开时聚焦首项。
- 序章可交互学生、第二章关键 NPC 和第三章任务入口使用场内 `!` 标记或明确任务提示。
- 章节风险预检查对玩家只给出简化状态描述；具体风险/画像数值留在后端。
- 失败分支统一回到既定的“陈继南家中醒来”链路，未改变历史固定节点。
- 终局面板只接受 Enter/Space/Escape，不会被任意键提前关闭。

### 4. 人物、尺寸、头像和画风

- 对话头像使用统一 `avatarCatalog`，发言者名称、人物头像和场景角色不再在各场景内重复硬编码。
- 第三章年长队员、彭定邦运行时素材改用透明裁切后的三/四头身资产，修正了原始绿底/棋盘底不能直接进场的问题。
- 运行时与玩家可见文本统一使用“董云庭”；本轮只将 `export (2)` 正面人物素材转换为 `ch03-dong-yunting/idle.png`，保留已确认的 `ch03-dong-yunting/avatar.png` 对话头像不变。“董锦堂”仅保留在旧美术来源文件名/史料来源边界，不作为第二个运行时角色。
- 人物显示高度通过 actor visual profile 控制；前景遮挡、碰撞底部和深度排序继续由统一 actor/collider 配置处理。

### 5. 后端核心系统与保存

- 风险系统与画像系统保持独立：选择通过统一接口分别写入 `risk` 和 `profile`，不会用画像值覆盖风险值，也不会用风险分支改变画像累计。
- 选择前端已移除 `detail` 数值展示；后端 `FormalChoiceDefinition` 仍保留完整增量与标签。
- 存档增加版本、checksum、坏档回退、v1 迁移和章节入口快照；章节重玩支持第一至第四章，并清理目标章节的局部标签而保留前置章节状态。
- 终局画像根据全章累计结果统一映射到九张海报，Esc 返回标题界面。

## 四、需要内容方确认的单项

第三章逐项选择的运行时效果与剧本节点一致，但剧本“章末核查”理论区间表按代码逐项加总后不一致：

- 逐项加总：`D10 / C14 / I16 / G20 / P10 / A6`；执行风险 `-5..7`；协同风险 `-5..12`。
- 文档表格：`D8 / C13 / I12 / G14 / P8 / A6`；执行风险 `-4..8`；协同风险 `-4..12`。

本轮没有为了追齐表格而改动任何玩家选择效果，因为那会使节点剧情与代码脱节。契约脚本会继续以“PASS WITH SPEC RANGE NOTE”通过并输出差异，待内容方确认总表后再做一次单独的数值锁定。
