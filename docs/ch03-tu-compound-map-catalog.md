# 第三章杜家大院地图状态目录

地图资源基线：`MAP_CH3_TU_COMPOUND_ALL_STATES_7L_v01`。

运行时采用 Phaser 的 `layeredMap` 契约：每个状态读取 6 张可见图层，L05 碰撞/交互 JSON 作为数据读取，不把编辑器预览 PNG 当作游戏图层。七个状态保持同一张 1664×936 画布和同一组空间锚点，供剧情节点切换。

| 状态 | 对应剧情情境 | 当前接入状态 |
|---|---|---|
| `STATE_WAITING` | 抵达外围、风险预检查、等待行动时的观察 | 第三章开场视频后的首个地图状态 |
| `STATE_GATE_CLOSED` | 三路行动展开、正门落闩 | 已资产化，待行动场景调用 |
| `STATE_GATE_ATTACK` | 前门撞击受阻 | 已资产化，待撞门节点调用 |
| `STATE_FIRE_STARTED` | 榨房起火、浓烟与火光改变现场 | 已资产化，待火攻节点调用 |
| `STATE_GATE_BROKEN` | 大门破开、三路队伍合拢 | 已资产化，待固定历史节点调用 |
| `STATE_AFTER_BATTLE` | 武器、财物、伤员集中清点 | 已资产化，待战后交互调用 |
| `STATE_DEPARTURE` | 小组重新集合、分批离场 | 已资产化，待章末转场调用 |

## 空间锚点

- 左下：前门土路、树影隐蔽区和墙外残食；
- 中下：高院墙与铁皮双门；
- 左上：院内宴饮/团丁生活区；
- 右上：封闭式湖北传统榨房；
- 右侧：武器与财物集中区；
- 左侧：战后伤员休息区；
- 上方：后院/街面方向出口。

## 剧情边界

本目录只记录地图状态与运行时资产契约，不把“涂家大院”等美术交付旧称谓写入玩家面向文本。第三章玩家面向剧情统一使用“杜家大院、杜老三、董云庭”。史料边界、固定历史节点和风险数值仍以第三章剧本与系统契约为准。
