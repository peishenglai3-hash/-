# 第一章：陈继南家中



## 场景：醒来的名字



【画面】



序章末尾的场景保持不变。



陈继南伏在旧木桌边。油灯的火苗很小，灯芯结着黑色的焦头。桌上摆着粗瓷碗、一册线装书、砚台和几张压在镇纸下的纸。



屋里没有现代物件。



木门半掩着，门缝外是一片被夜色压低的院子。远处虫鸣不断，偶尔夹着一两声犬吠。



坐在桌边的女人没有立刻伸手碰你。她先看了看你的脸，又看了一眼窗外。



【对话｜家人】



“继南？你这是怎么了？”



【旁白】



她问得很轻。碗里的饭已经凉了一些，筷子却还规规矩矩搭在碗沿，像是一直在等你回过神来。

笔记本、录音笔，和白天发生的种种，全像被人从手边抽走了。只剩下被压得发麻的双手，和一句不能轻易答错的话。”



【心理描写】



“她认识“我”。可我不认识她。”



“我的手好麻。”



【可行走范围】



玩家恢复控制，可在屋内有限区域行走：



- 木桌与书案附近；

- 铜盆旁；

- 门边；

- 家人身前。

【交互｜铜盆】



铜盆里的水没有完全静下来。



你靠近时，水面先映出房梁上的油灯，再映出一张年轻男人的脸。眉骨、鼻梁、下巴都陌生。



【心理描写】



“这是谁”



【旁白】



洗脸架上搭着一条洗得发硬的布巾。铜盆里水光荡漾，盆上有经年累月磨洗的痕迹。

【交互｜书案】



书案一角压着一册线装书。书页边缘被翻得起毛，夹页里露出半张练字纸。



纸上有几行未写完的字。

“这个名字不是家人随口叫出来的，也不是我听错了。它留在纸上，留在这具身体原本会伸手去拿的地方。”



【旁白】



纸张旁边摆着毛笔和砚台。笔杆磨得光滑。砚中的墨还没有完全干透。

# 闪回一：状纸



【说明】



此段为陈继南身体所携带的片段性反应。其叙事原型来自刘绍南后人口述，移植为陈继南记忆，属于情境化改编。



【画面】



屋门前仍是一张木桌，只是桌上的油灯更亮，窗外还是白日。



一个衣角沾着水渍、身着斗笠蓑衣的渔民站在门槛外。他没有进屋，双手一直攥着一张被揉得发皱的文书。



少年陈继南坐在桌旁，年纪比现在更小些。



【对话｜渔民】



“俺也去过几处。人家一听是湖上的事，就说写不得。”



【对话｜少年陈继南】



“谁不让你下湖？”



渔民没有立刻回答。他先回头看了一眼门外，才把声音压下去。



【对话｜渔民】



“不是不让下湖。是下了湖，打的鱼要交；不交，就说我占了张财主家的水面。”



【旁白】



他说得很小心，怕自己讲错一个字，就连最后一点求人的资格也没有了。



少年陈继南没有立刻提笔。他问起湖在哪一段、对方什么时候来收、家里靠什么过日子，又让渔民把已经交过的东西一项项说清。



【音效】



笔尖落在纸上的沙沙声。（毛笔会有沙沙声吗？）



【旁白】



字并不华丽，但一笔一画写得很稳。事情从哪里起、受了什么亏、想请人查明什么，都被写在同一张纸上。



【画面】



渔民接过状纸时不敢用力。



纸上的场景没有继续展开为审案结果。只有一段由身体残留而来的、断断续续的感受：



有人愿意收下状纸；有人终于把受的委屈讲清；几天后，渔民又来过一次，空着的手里多了一包用布裹好的干鱼。



【对话｜渔民】



“我没别的东西。这个你收下。”



【对话｜少年陈继南】



“留给家里。”



【画面】



墨迹重新漫开，覆盖了桌面。



【心理描写】



“这不是我的记忆。”



“可是那种那种迟疑过后仍决定写下去的感觉，我还记得。”

## 院墙阴影下：联络通知



【触发】



玩家回应暗号或接受联络人的示意后，走到院墙阴影下。



屋里的油灯被木门挡住，只剩一线昏黄。家人留在屋内，听不清外面的低语。



【画面】



联络人站在背风处，没有靠得太近。他先看了看院门，又看向屋内，确认没有旁人跟出。



【对话｜联络人】



“陈家祠堂。人已经到了。”



他停顿片刻，像是在判断你是否听清。



【对话｜联络人】



“别走大路。到了以后先找自己那一边的人，别乱挤，别乱问。今夜人多，听安排。”



【旁白】



他没有说行动内容，没有说目标，也没有说会有多少人。



这些话只告诉你该去哪里、如何到达，以及到了以后不要擅自行动。



【心理描写】



“陈家祠堂。好熟悉。对了，我在搜集到的史料里见到过。”



“可我在材料中读到的是已经发生过的历史。难不成，我现在还在它尚未发生的夜里？”



“门里，有一个不知道内情的家人。门外的人也没有把地点说给她听。”



“每个人都在少说一句。”



〔史〕陈家祠堂为戴家场秋收暴动会前集结、开会与出发地点，本作采用正式史实口径。〔史1〕  

〔虚〕联络人、敲门方式、暗号、联络台词及具体路线均为连接游戏流程的虚构设计。  

〔改〕联络人避开家属后再传达地点，以及“不在门口谈论行动、不主动询问无关内容”等处理，依据秘密行动的一般保密原则进行情境化重构，不宣称为戴家场当夜留存的逐字命令。

|协同风险|0|0—1|0—1|



### 风险来源



- **身份风险**：直接否认自身身份、在暗号环节过度追问、告别时表现出明显异常；

- **执行风险**：本章尚未进入正式行动执行，因此不产生变化；

- **协同风险**：在门前连续追问，影响联络节奏。

    

本章不设置失败阈值。身份风险较高时，只产生轻度反馈：



- 家人更加留意陈继南的异常；

- 联络人减少主动说明；

- 下一章在祠堂接头时增加身份确认；

- 玩家可能被安排在更容易观察、但行动自由度较低的位置。

    

失败条件仍待后续章节全部节点完成后统一校准。达到失败条件时，统一返回“陈继南家中醒来”节点。
