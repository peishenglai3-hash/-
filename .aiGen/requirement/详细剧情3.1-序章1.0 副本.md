# 序章：名字留在纸上



## 序章定位



【说明】  

现代大学生随暑期实践队走访刘绍南烈士纪念碑。走访结束后，玩家将白天留下的照片、笔记与采访录音带回实践驻地整理，并在疲惫中伏案睡去。



【说明】  

序章不提前完整讲述戴家场秋收暴动，而是留下三个尚未回答的问题：



- 刘绍南是谁？

- 那个中秋夜发生了什么？

- 当一个人真正身处历史现场时，他会怎样判断、怎样行动，又会依靠谁？

    

【说明】  

序章只设置一个正式选择节点。玩家的选择不改变穿越结果，但会影响最终画像和现代结尾的呼应内容。

# 场景一：暑期实践的最后一项记录



【说明】  

时间：现代，夏日傍晚。  

地点：戴家场刘绍南烈士纪念碑附近。



【说明】  

纪念碑、实践队员、设备包和记录材料在进入场景时整体呈现。



【说明】  

碑面正式文字、碑体形制及周边环境，均须根据现场实拍资料还原，不自行补写。



【旁白】  

昼暑将消。白天蛰伏在墓地的巨兽，此刻蠢蠢欲动，黑夜将要降临在江汉平原。夏天的野草长得有些太盛了，人影浸没在热风和夕光里，实践队的采访工作已经结束，同学们正将散落的设备一件件收回包里。



【音效】  

树叶摩擦声、设备包拉链声、纸页翻动声。远处偶尔有车辆经过，声音很快又被夏日的虫鸣吞没。



【画面】  

一名同学蹲在设备包旁，将录音笔、充电宝和几张编号过的采访记录逐一核对。



【对话｜同学甲】  

“录音文件都在，采访登记也对上了。”



【画面】  

另一名同学把相机收进包里，又抬头看了看天色。



【对话｜同学乙】  

“天快黑了，差不多我们就回去吧。”



【旁白】  

你应了一声，却没有立刻合上手里的实践笔记。白天采访留下的内容并不完整。姓名、地点和时间散落在不同人的叙述里，有些话听得清楚，有些话却在蝉鸣、停顿和方言里变得面目模糊。整理到最后，最清晰的反而只是一个反复出现的名字。



【画面】  

实践笔记上的一处记录被突出显示：



**刘绍南。**



你抬起头，看向纪念碑。



【旁白】  

纪念碑同样浸没在傍晚的天光里，像一枚琥珀。天色渐暗，碑面上的笔迹好像被风吹乱。你弯下身子，眯起眼来认细细辨认，手指抚过一道道凹痕——你认识这个名字。



【画面】  

同学们已经收好了大部分设备。只有少量记录材料仍留在外面。



【心理描写】  

“我还得再确认一件事。”

【画面】

【画面】
