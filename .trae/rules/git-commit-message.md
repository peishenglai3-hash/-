# Git 提交信息规范

生成提交信息时遵循以下规则：

- 提交信息一律使用**中文**编写。
- 采用约定式提交（Conventional Commits）格式：`<类型>: <描述>`。
- 类型示例：`feat`（新功能）、`fix`（修复）、`refactor`（重构）、`docs`（文档）、`style`（样式）、`test`（测试）、`chore`（杂项）。
- 描述用一句话说明变更内容与目的，聚焦“为什么”而非罗列细节。
- 保持简洁，避免空泛或无意义的描述（如“更新”“修改”）。
