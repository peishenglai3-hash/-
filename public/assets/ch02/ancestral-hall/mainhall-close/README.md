# MAP_CH2_ANCESTRAL_HALL_MAINHALL_CLOSE

Canvas: 1664×936 px
Tile basis: 48×48 px
Coordinate origin: top-left

## Layer order

1. L01_GROUND — base ground and floor surfaces
2. L02_GROUND_DETAIL — cracks, stains, footprints and small ground marks
3. L03_STRUCTURE_LOW — low walls, door/threshold, steps and column bases
4. L04_PROP_INTERACT — furniture, deployment props, parcels, buckets and weapons
5. L05_COLLISION_TRIGGER — editor-only collision/trigger overlay plus JSON objects
6. L06_OCCLUSION_HIGH — roofs, eaves, upper structure and foliage occlusion
7. L07_LIGHT_FX — lamp pools and night-light effects

The seven PNG files share the same 1664×936 canvas and top-left origin. Keep L05 hidden at runtime and load its JSON as the object layer.
